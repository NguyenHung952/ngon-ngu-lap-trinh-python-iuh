# 🐍 Ngôn ngữ Lập trình Python – IUH

Repository lưu trữ các **bài tập Python theo từng phần/bài** của môn Ngôn ngữ Lập trình Python tại IUH.

## 📂 Cấu trúc

```text
ngon-ngu-lap-trinh-python-iuh/
├── bai-tap/
│   ├── bai_tap_python_1.zip
│   ├── bai_tap_python_2.zip
│   ├── ...
│   └── bai_tap_python_12.zip
└── README.md
```

## 🎯 Mục tiêu

- Thực hành cú pháp và tư duy lập trình Python
- Lưu trữ bài tập theo từng phần
- Thuận tiện ôn tập và thực hành lại

## 🛠 Công cụ

- Python 3
- IDE/Python environment tùy bài tập

## ▶️ Sử dụng

Giải nén bài tập cần làm và chạy project/file Python bên trong bằng môi trường Python phù hợp.

> Chỉ tổ chức lại các file ZIP vào `bai-tap/`; nội dung bài tập được giữ nguyên.
